# Herbert Okuthe — The Voice of Your Vision

A responsive Next.js campaign landing page for CMU-Africa Communications Minister.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. For a production build, run `npm run build`.

## Before publishing

- Replace the initials-only hero portrait and About portrait with a real candidate photo. These are intentional placeholders; no photograph was provided.
- Confirm official voting hours and voting instructions with the election organizers. The countdown currently targets **08:00 Africa/Kigali, 14 November 2026**, an illustrative time, not a verified polling opening time.
- Review statements about alumni and faculty contacts and obtain permission before publicly naming individuals.
- Add your preferred campaign social links and any official voting URL once confirmed.
- The website is independently campaign-branded and does not use the CMU logo. Red uses CMU brand red `#bb0000`.
